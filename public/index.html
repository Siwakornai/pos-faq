    ⚙️ ตั้งค่าการเชื่อมต่อ EatAi & ระบบเก็บ Feedback

    ที่เก็บข้อมูล Feedback (3 ช่องทาง):
    1. LocalStorage ในเครื่องอัตโนมัติ: เก็บไว้ในคีย์ e365_eatai_feedbacks เปิดดูได้ทันทีผ่านปุ่ม 📊 Feedback
    2. Export CSV / Excel: ดาวน์โหลดเป็นไฟล์ตารางไปเปิดใน Excel หรือ Google Sheets ได้ตลอดเวลา
    3. Google Sheets อัตโนมัติ (เมื่อใส่ URL ด้านบน): ส่งค่า Thumbs Up/Down + Comment เข้าชีตทันที

    สถานะแหล่งข้อมูลของ EatAi
    • ลำดับที่ 1: Q&A POS Knowledge Bank (Google Sheets) เปิดใช้งาน
    • ลำดับที่ 2: Eats365 Support Knowledge Base (เมื่อไม่มีในชีต) เปิดใช้งานอัตโนมัติ

    📊 ศูนย์รวมข้อมูล Feedback ของ EatAi (Feedback Log & Storage)

    ข้อมูลถูกบันทึกอัตโนมัติในเบราว์เซอร์ (localStorage: e365_eatai_feedbacks) และสามารถ Export เป็นไฟล์ CSV หรือเชื่อมเข้า Google Sheets ได้

    1. เปิดไฟล์ Google Sheets ของคุณ > ไปที่เมนู Extensions (ส่วนขยาย) > Apps Script
    2. วางโค้ดด้านล่างนี้ลงไป แล้วกด Deploy > New deployment > เลือกประเภท Web app (ตั้งค่า Who has access เป็น Anyone)
    3. คัดลอก Web app URL มาใส่ในช่องตั้งค่าของเว็บนี้ ระบบจะยิงข้อมูลเข้าชีตทันทีทุกครั้งที่มีคนกด 👍/👎 หรือคอมเมนต์!
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('EatAi_Feedback') || SpreadsheetApp.getActiveSpreadsheet().insertSheet('EatAi_Feedback');
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['Timestamp', 'Rating', 'Comment', 'User Question', 'EatAi Response']);
  }
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.timestamp, data.rating, data.comment || '-', data.question, data.answer]);
  return ContentService.createTextOutput(JSON.stringify({status: 'ok'})).setMimeType(ContentService.MimeType.JSON);
}
